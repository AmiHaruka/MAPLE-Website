Installation Guide

This guide walks you through installing MAPLE and its dependencies on your system. MAPLE supports Linux and macOS, with optional GPU acceleration via CUDA.

Requirements

Before installing MAPLE, ensure your system meets the following minimum requirements:

Requirement Details
Python >= 3.10
GPU CUDA-capable GPU recommended (NVIDIA)
RAM 4 GB+ (8 GB+ recommended for large systems)
Disk Space ~2 GB for MAPLE and model files
OS Linux or macOS
Tip: GPU Acceleration

While MAPLE runs on CPU, a CUDA-capable GPU significantly speeds up ML potential evaluations. If you have an NVIDIA GPU, install PyTorch with CUDA support (see below) for the best performance.

Install MAPLE

Clone the MAPLE repository and install it in development mode:

# Clone the repository
git clone https://github.com/ClickFF/MAPLE.git
cd MAPLE

# Install in editable/development mode
pip install -e .

This installs MAPLE as a Python package and makes the maple command available in your terminal. The -e flag enables editable mode, so any changes to the source code take effect immediately without reinstalling.

For users in China

Follow the same installation order above. If PyPI downloads are slow, append the Tsinghua mirror option to the editable install command:

# From the MAPLE repository root
pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple

The same -i https://pypi.tuna.tsinghua.edu.cn/simple option can also be appended to later PyPI-based pip install commands on this page, such as the core dependencies or fairchem-core.

MAPLE auto-downloads supported MAPLE-hosted model files from https://huggingface.co/Wayne7815/MAPLE_models. If you download model files manually through a reachable mirror, keep the same filenames and place them in maple/function/calculator/model/.

Tip:
- If access to Hugging Face is slow in your region, you can use the mirror https://hf-mirror.com/Wayne7815/MAPLE_models/tree/main for manual model file downloads.
- If the local model directory does not exist, create maple/function/calculator/model/ before placing files there.

Install Dependencies

Core Dependencies

The core scientific libraries are installed automatically with pip install -e ., but you can also install them manually:

pip install numpy scipy ase

PyTorch

MAPLE requires PyTorch for ML potential inference. Install the version that matches your hardware:

With CUDA support (recommended for GPU):

pip install torch --index-url https://download.pytorch.org/whl/cu121

CPU only:

pip install torch --index-url https://download.pytorch.org/whl/cpu
Note

Check your CUDA version with nvidia-smi and choose the matching PyTorch CUDA build (e.g., cu118, cu121). Visit pytorch.org for detailed instructions.

ML Potentials

ANI, AIMNet2, MACE, MACE-Polar, and UMA use torch-backed runtimes, so install PyTorch separately for your hardware before using them. Install fairchem-core only when you need UMA or FAIR-Chem-backed/PBC workflows:

pip install fairchem-core

Install JAX/Flax only when you use FeNNol .fnx models:

# CPU
pip install -U jax flax

# NVIDIA GPU (CUDA 12)
pip install -U "jax[cuda12]" flax

Checkpoint and runtime boundaries:

  • Core install: pip install -e . installs MAPLE plus ase, numpy, and scipy; it does not select a PyTorch/CUDA stack for you.
  • MAPLE-hosted checkpoints: ANI, AIMNet2, maceoff23m, and egret can be auto-downloaded from MAPLE_models.
  • Local checkpoints: backend-specific files such as maceoff23s, maceoff23l, maceomol, and MACE-Polar checkpoints must be placed in maple/function/calculator/model/ or supplied through model_path.
  • FeNNol : built-in fennix-bio1s and fennix-bio1m resolve shipped .fnx files; generic fennol requires model_path=/path/to/model.fnx.
  • UMA: UMA checkpoints resolve through checkpoint_path, a local maple/function/calculator/model/uma-*.pt file, or FAIR-Chem's official loading path.

See the calculator backend matrix for the exact PBC, charge/multiplicity, Hessian, D4, solvent, HVP, and checkpoint support of each backend.

Verify Installation

After installation, verify that MAPLE is correctly set up by running:

maple --help

You should see the MAPLE help output listing available commands and options. If the maple command is not found, ensure your Python environment's bin directory is on your PATH.

You can also verify GPU availability:

python -c "import torch; print('CUDA available:', torch.cuda.is_available())"
Warning

If torch.cuda.is_available() returns False on a system with a GPU, check that your NVIDIA drivers and CUDA toolkit are properly installed and that you installed the CUDA-enabled version of PyTorch.
