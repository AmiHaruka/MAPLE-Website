AIMNet2 and AIMNet2-NSE

The AIMNet family uses local atomic environment features and iterative message passing to predict energies and charges. MAPLE includes two architectures: AIMNet2, with one charge channel and neural charge equilibration, and AIMNet2-NSE, with two spin-dependent charge channels. Their pretrained models differ in reference data, chemical coverage and electronic-state conditions.

Models by Architecture

AIMNet2

These models use a single charge channel. The current RXN model is restricted to neutral systems; the other listed models accept total charge. All require multiplicity 1.

Keyword Elements Reference / Model Focus Electronic State
aimnet2 H, B, C, N, O, F, Si, P, S, Cl, As, Se, Br, I ωB97M-D3(BJ)/def2-TZVPP; neutral and charged organic and main-group molecules Charge; multiplicity 1
aimnet2-rxn H, C, N, O ωB97M/def2-TZVPP; closed-shell organic reactions, transition states and reaction pathways Neutral; multiplicity 1
aimnet2-pd H, B, C, N, O, F, Si, P, S, Cl, Se, Br, Pd, I B97-3c/CPCM(THF); palladium-catalyzed reactions Charge input; multiplicity 1
aimnet2-b973c H, B, C, N, O, F, Si, P, S, Cl, As, Se, Br, I B97-3c; molecular conformations and energetics Charge; multiplicity 1
aimnet2-2025 H, B, C, N, O, F, Si, P, S, Cl, As, Se, Br, I B97-3c; improved intermolecular interactions Charge; multiplicity 1

AIMNet2-NSE

The NSE architecture uses two charge channels to condition on total charge and spin multiplicity.

Keyword Elements Reference / Model Focus Electronic State
aimnet2-nse H, B, C, N, O, F, Si, P, S, Cl, As, Se, Br, I ωB97M-D3(BJ)/def2-TZVPP; open-shell molecules and radical reactions Charge and multiplicity

Charge and Spin Support

Use aimnet2-nse when the input requires spin-multiplicity conditioning. The listed AIMNet2 models require multiplicity 1, and aimnet2-rxn additionally requires charge 0. Specify the electronic state in the coordinate block:

#model=aimnet2
#opt(method=lbfgs)

-1 1
C    0.000000    0.000000    0.000000
O    1.250000    0.000000    0.000000
O   -1.250000    0.000000    0.000000

The first line specifies charge multiplicity (here: charge = −1, multiplicity = 1 for an anion).

Energy-only Implicit Solvation

AIMNet2 can use MAPLE's experimental implicit GB-polar/QEq correction for single-point energies. Add experimental=true and use #sp; solvent forces, optimizations, Hessians, and frequency workflows are not supported for this correction.

#model=aimnet2
#solv(method=gbsa, implicit=water, experimental=true)
#sp

-1 1
C    0.000000    0.000000    0.000000
O    1.250000    0.000000    0.000000
O   -1.250000    0.000000    0.000000

Calculator Capabilities

  • Hessian: analytic Hessians are used by default; numerical Hessians are also available.
  • HVP: all six AIMNet2 and AIMNet2-NSE models provide Hessian–vector products.
  • Periodic systems: periodic inputs require full three-dimensional periodicity; stress and virial output are available.
  • Atomic charges and dipoles: both properties are available from the native charge output.
  • Implicit solvent: the experimental GB-polar/QEq correction supports non-periodic single-point energies only (#sp with experimental=true); solvent forces, Hessians and HVPs are unavailable.

Long-Range Options

Periodic inputs require a full three-dimensional cell. lr=auto selects the native molecular or periodic long-range route. The lr choices are auto, simple, dsf, ewald and pme; availability follows the boundary conditions and the selected model's Coulomb term.

Option Default Description
lr auto Native long-range selection.
lr_cutoff 15.0 DSF cutoff in Angstroms.
dtype float32 Supported value: float32.

Usage Examples

Optimization with heavy elements (Br, I)

#model=aimnet2
#device=gpu0
#opt(method=lbfgs)

0 1
C    0.000000    0.000000    0.000000
Br   1.940000    0.000000    0.000000
H   -0.390000    0.000000    1.028000
H   -0.390000    0.890000   -0.514000
H   -0.390000   -0.890000   -0.514000

AIMNet2-NSE with neural spin-charge equilibration

#model=aimnet2-nse
#device=gpu0
#opt(method=lbfgs)

0 1
C    0.000000    0.000000    0.000000
I    2.140000    0.000000    0.000000
H   -0.390000    0.000000    1.028000
H   -0.390000    0.890000   -0.514000
H   -0.390000   -0.890000   -0.514000

Limitations

  • Electronic state: use the conditions in the variant table; spin conditioning is provided by NSE.
  • Elements: RXN is limited to H, C, N, O; the Pd variant substitutes Pd for As in the standard element set.
  • No D4 dispersion. MAPLE's separate D4 correction is not supported by AIMNet2 or AIMNet2-NSE.
